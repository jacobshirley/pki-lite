# x509-limbo

Test cases from [x509-limbo](https://github.com/C2SP/x509-limbo), a suite of X.509 path
validation cases with expected results, used by `test/unit/x509-limbo.test.ts`.
x509-limbo is licensed under the Apache License 2.0; the certificates, CRLs and case
descriptions here are taken from its `limbo.json` unchanged.

`limbo.ts` is generated by `generate.sh`; don't edit it by hand. It holds every case
except the BetterTLS ones (about 9,600 name-constraint and path-building cases with 24 MB
of certificates, too large to commit), with each certificate and CRL stored once as
base64 DER, so the suite runs in both the node and browser vitest projects.

The test skips the cases outside an RFC 5280 validator (CA/Browser Forum Web PKI profile
rules, ML-DSA), each with the reason, and lists the cases pki-lite does not pass yet in
its `KNOWN_ISSUES`.

To regenerate (the download is pinned by commit and SHA-256):

```sh
./generate.sh    # needs curl, sha256sum and python3
```
